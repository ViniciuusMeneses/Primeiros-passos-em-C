# Primeiros passos em C

Meus primeiros programas em C, do "Hello World" a vetores e matrizes, feitos nas aulas de Engenharia da Computação no CESUPA e em treinos no beecrowd.

## Como compilar

```bash
gcc atividades/fatorial.c -o fatorial -lm
./fatorial
```

O `-lm` só é necessário nos programas que usam `math.h`.
